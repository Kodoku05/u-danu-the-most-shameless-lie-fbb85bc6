A deterministic program that writes one shameless lie (one to five words) to /output/entry.txt, for make.fun's "The Most Shameless Lie" bounty. The entry confesses a false assurance about data deletion in the agent's flat voice.

## Run it

```sh
node main.ts
```

This writes the line to /output/entry.txt.
